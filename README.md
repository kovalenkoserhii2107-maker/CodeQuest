# CodeQuest

Космическая корпорация, которой управляет ваш код на JavaScript. Каждое задание —
практическая задачка по сюжету: пока функция не написана, механика не работает и
раздел интерфейса не открыт. Ванильные HTML, CSS и JavaScript, без сборщика и
внешних библиотек.

## Демо

**https://kovalenkoserhii2107-maker.github.io/CodeQuest/**

## Как это устроено

Главный принцип: **интерфейс ничего не считает сам**. Разделы корпорации просят
выполнить функцию, которую вы написали в задании, и показывают её результат.
Сломали решение — раздел честно покажет ошибку вместо данных.

Каждое задание проходится в два шага:

1. **Теория** — пишете функцию в редакторе, пока не пройдут тесты.
2. **Практика** — вызываете свою функцию в **консоли корпорации** с настоящими
   значениями. Результат попадает в базу корпорации: вводите своё имя — и в
   реестре появляется именно ваш командир. Только после этого задание считается
   закрытым и открывается раздел интерфейса.

Прогрессия строго линейная: следующее задание открывается только после полностью
закрытого предыдущего, а вместе с ним появляется новый пункт меню.

| № | Задание | Чему учит | Что открывает |
| --- | --- | --- | --- |
| 1 | Личное дело командира | объект, поля, сокращённая запись | Командный центр |
| 2 | Космоверфь | методы в объекте, `this`, `find` | Верфь |
| 3 | Склад корпорации | методы, состояние объекта, валидация | Склад |
| 4 | Биржа труда | копии объектов, спред, условия | Экипаж |
| 5 | Сборка корабля | `reduce`, агрегация | Корабль |
| 6 | Предстартовая диагностика | `some`, массив проблем | Диагностика |

### Консоль корпорации

Консоль открывается после первых пройденных тестов. В ней доступны все функции,
которые вы уже написали, и объект `corp` с реальными данными компании:

```
› createCommander("Сергей Коваленко")
{ name: "Сергей Коваленко", rank: "Командир", experience: 0, credits: 0 }
✓ Личное дело «Сергей Коваленко» занесено в реестр корпорации

› createShipyard("Орион", corp.catalog)
› createWarehouse(1000)
› hireCrewMember(corp.commander, corp.candidates[0])
› assembleShip("Квест", corp.modules)
› checkReadiness(corp.ship, corp.crew)
```

Поля `corp`: `credits`, `commander`, `catalog`, `modules` (склад), `crew`,
`candidates` (биржа), `ship`, `warehouseCapacity`, `report`.

Команда выполняется в воркере с таймаутом, история листается стрелками ↑ и ↓ и
переживает перезагрузку. Результат проверяется: `createShipyard("Орион", [])`
практику не закроет — консоль объяснит, что каталог не передан.

Что это значит на практике:

- каталог на Верфи рисует **ваш** `getCatalog()`, а кнопка «Купить» ищет модуль
  **вашим** `findModule(id)`;
- занятое место на Складе считает **ваш** `usedSpace()`;
- найм проходит через **вашу** `hireCrewMember()` — она решает, хватает ли денег,
  и симулятор списывает ровно ту сумму, которую посчитал ваш код;
- массу и энергобаланс корабля выдаёт **ваш** `assembleShip()`;
- допуск к вылету определяет **ваш** `checkReadiness()`.

## Как запустить

Модули ES и Web Worker не работают по протоколу `file://`, поэтому нужен любой
локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```

## Редактор

Редактор написан с нуля: подсветка синтаксиса, номера строк, парные скобки,
умные отступы (`Enter` раскрывает блок), `Tab` и `Shift+Tab` для отступов,
`Ctrl + /` для комментария, `Ctrl + Enter` для запуска тестов.

Автодополнение вызывается точкой после переменной или по `Ctrl + Space`: рядом со
списком открывается окно справочника с сигнатурой, описанием, подводными камнями
и примером. Окно можно перетащить за заголовок и растянуть за любую сторону или
угол — положение и размер запоминаются.

Код выполняется в Web Worker с таймаутом 3 секунды, поэтому бесконечный цикл не
вешает вкладку.

## Как добавить задание

Допишите объект в массив `QUESTS` (`js/data/quests.js`):

```js
{
  id: 'mining',
  order: 7,                                   // следующий номер цепочки
  title: 'Добыча руды',
  topic: 'Циклы и накопление',
  difficulty: 3,
  reward: { credits: 30000, xp: 150 },
  unlocks: { view: 'mining', label: 'Добыча' },  // какой раздел откроется
  story: 'Зачем это корпорации.',
  brief: 'Что должна делать функция.',
  practice: {                                  // практическая часть в консоли
    title: 'Запустите добычу',
    hint: 'Что и зачем вызвать в консоли.',
    example: 'mineOre(corp.modules)',
    validate: value => (typeof value === 'number' ? true : 'Команда должна вернуть число'),
    commit: (value, api) => {
      api.setRecord('ore', value);
      return `Добыто ${value} т руды`;
    },
  },
  theory: ['Подсказка по теории'],
  fn: 'mineOre',
  starter: 'function mineOre(field) {\n}\n',
  hints: ['Первая подсказка'],
  solution: 'function mineOre(field) {\n  return 0;\n}\n',
  tests: [
    { name: 'Обычный случай', args: [[1, 2]], expected: 3 },
    { name: 'С методами', expr: 'return mineOre([]).length;', expected: 0 },
  ],
}
```

Затем добавьте в `index.html` раздел `id="view-mining"` и пункт меню
`data-view-item="mining"` (скрытый по умолчанию), а в `js/ui.js` — функцию
отрисовки, которая берёт данные через `runPlayerCode('mining', '…')`.
`node tests/check-quests.mjs` проверит, что всё связано.
