# CodeQuest

Игровой тренажёр JavaScript в антураже космической корпорации: решаете
практические задачи — улучшаете корабль и открываете новые секторы карты.
Ванильные HTML, CSS и JavaScript, без сборщика и внешних библиотек.

## Демо

Игра опубликована на GitHub Pages:
**https://kovalenkoserhii2107-maker.github.io/CodeQuest/game.html**

Корень сайта (`/CodeQuest/`) открывает центр управления корпорации, оттуда есть
переход в тренажёр. Сайт собирается из ветки `main`: после каждого слияния
GitHub пересобирает страницы автоматически.

## Что внутри

| Страница | Что это |
| --- | --- |
| `game.html` | Тренажёр: карта секторов, Мостик, схема корабля, задачи с редактором кода, журнал |
| `index.html` | Центр управления корпорации — витрина интерфейса |
| `missions.html` | Реестр миссий и форма заявки на запуск |

Игровой цикл: на **карте** выбираете сектор → решаете **задачу** в редакторе →
тесты проходят → растёт уровень **модуля корабля**, оживает прибор на **Мостике**,
начисляются кредиты и опыт → открывается следующий сектор. Прогресс хранится в
`localStorage`, приложение ставится как PWA и работает офлайн.

### Мостик — приборы на вашем коде

Главная особенность: показания приборов считает не игра, а ваш код. Решили
задачу «Датчик топлива» — на Мостике заработал датчик, и его значение вычисляет
ваша функция `fuelPercent` на настоящих данных корабля (318 т из 400). Пока
задача не решена, прибор «не откалиброван» и подсказывает, какой функции ждёт.

Если код проходит тесты, но спотыкается на данных корабля, прибор honest-но
покажет ошибку вместо значения — это повод доработать решение. Данные приборов
лежат в `js/data/ship-data.js`, привязка «задача → прибор» — в
`js/data/dashboard.js`.

### Редактор кода

Редактор написан с нуля, без CodeMirror и Monaco: офлайн-режим и принцип
«без зависимостей» важнее пары килобайт функций, которые нам не нужны.

- **Парные скобки и кавычки.** Открыли `(` — закрывающая подставилась, курсор
  внутри. Набрали `)` перед автоматической скобкой — курсор просто перешагнёт её.
  Выделили текст и нажали `(` — выделение обернётся в скобки. Backspace между
  пустой парой удаляет обе скобки.
- **Умные отступы.** Enter сохраняет отступ строки, после `{` добавляет уровень,
  а между `{` и `}` раскрывает блок с закрывающей скобкой на своей строке.
  `}` в начале строки подтягивается влево. Tab и Shift+Tab двигают выделенные
  строки, Ctrl + / комментирует их.
- **Подсветка синтаксиса** и номера строк — свой мини-токенизатор
  (`js/editor/highlight.js`), цвета настроены для обеих тем.
- **Автодополнение со справкой.** Точка после переменной открывает список
  методов, а рядом — окно с описанием: сигнатура, что делает, подводные камни,
  что возвращает и рабочий пример. Тип значения определяется по объявлению
  переменной (`const routes = []` → методы массива), по результату метода
  (`.split(...)` → массив) или по говорящему имени; если тип неясен, показываются
  методы всех типов с пометкой владельца. Ctrl + Space вызывает список
  принудительно, стрелки выбирают, Enter или Tab вставляют, Esc закрывает.
  В подсказки попадают и имена из вашего кода — функции, переменные, параметры.
- **Окно справочника — подвижное.** Его можно перетащить за заголовок в любое
  место редактора и растянуть за уголок в правом нижнем углу. Положение и размер
  запоминаются, поэтому окно больше не прыгает за кареткой и не закрывает код,
  который вы пишете. Кнопка ⤣ в заголовке возвращает окно к курсору, × закрывает
  его. Окно всегда удерживается внутри редактора: на телефоне сжимается по ширине
  и перестраивается — список сверху, описание снизу.

Справочник лежит в `js/data/js-api.js`: 68 записей про методы массивов и строк,
`Object`, `Math`, `Number`, промисы и ключевые слова — все описания на русском.
Чтобы добавить свою, допишите объект с полями `name`, `owner`, `signature`,
`summary`, `details`, `returns`, `example`.

### Шапка

- **Колокольчик** — последние события полёта; точка горит, пока есть непрочитанное.
- **Солнце/месяц** — переключение светлой и тёмной темы, выбор запоминается и
  действует на всех страницах.
- **Карточка пилота** — уровень, кредиты, прогресс и быстрые переходы.

## Как запустить

Модули ES и Web Worker не работают по протоколу `file://`, поэтому нужен любой
локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/game.html
```

Файл `.nojekyll` в корне отключает обработку Jekyll на GitHub Pages — статика
отдаётся как есть.

Service worker работает по стратегии «сначала сеть, кэш про запас»: после
обновления сайта вы сразу видите свежую версию, а офлайн по-прежнему открывается
из кэша.

Если открыть файл напрямую, игра всё равно запустится, но предупредит: код будет
выполняться в основном потоке, а офлайн-режим не включится.

## Задачи

14 задач в 5 секторах, по возрастанию сложности:

| Сектор | Модуль | Темы |
| --- | --- | --- |
| Док «Гелиос-9» | Реактор | переменные, числа, `Math`, условия |
| Пояс астероидов | Грузовой трюм | `reduce`, `filter`, `map`, циклы |
| Ретранслятор R-14 | Антенна связи | строки, разбор в объект |
| Орбита Марса | Навигация | сортировка, поиск, функции высшего порядка |
| Сектор Ξ-7 | Щиты, лаборатория | вложенные массивы, классы, `async/await` |

Решение проверяется набором тестов; при ошибке видно, что ожидалось и что
получилось. Есть подсказки, а эталонное решение можно открыть — оно засчитается
с половинной наградой.

## Как добавить свою задачу

Допишите объект в массив `QUESTS` (`js/data/quests.js`):

```js
{
  id: 'my-quest',            // уникальный идентификатор
  sector: 'belt',            // id сектора из SECTORS
  module: 'cargo',           // какой модуль корабля улучшает
  title: 'Название',
  difficulty: 2,             // 1…5, рисуется звёздами
  topic: 'Тема задачи',
  reward: { credits: 120, xp: 60 },
  brief: 'Условие задачи.',
  theory: ['Подсказка по теории', 'Ещё одна'],
  fn: 'myFunction',          // имя функции или класса, которое ждут тесты
  starter: 'function myFunction() {\n}\n',
  hints: ['Первая подсказка', 'Вторая'],
  solution: 'function myFunction() {\n  return 1;\n}\n',
  tests: [
    { name: 'Обычный случай', args: [1, 2], expected: 3 },
    // если нужен колбэк или объект с методами — тест пишется выражением:
    { name: 'С колбэком', expr: 'return myFunction([1], x => x);', expected: 1 },
  ],
}
```

Число задач модуля должно совпадать с его `maxLevel` в `js/data/modules.js` —
иначе уровни не сойдутся, и автопроверка об этом скажет. Для новой задачи нужен
прибор в `js/data/dashboard.js` (`expr` — что посчитать вашим кодом, `render` —
как это показать), иначе проверка тоже пожалуется: результат некуда выводить.

## Проверки

```bash
node tests/check-quests.mjs        # эталонные решения, заготовки, связность данных
node tests/check-editor.mjs        # редактор: скобки, отступы, подсветка, подсказки
# браузерный тест: откройте http://localhost:8000/tests/smoke.html
```

`tests/check-quests.mjs` следит за тем, чтобы каждое эталонное решение проходило
свои тесты, заготовка — нет, у каждой задачи был свой прибор на Мостике и этот
прибор считался без ошибок. `tests/smoke.html` проверяет в реальном браузере
запуск через Web Worker, прерывание зависшего решения по таймауту, расчёт
приборов и правила начисления наград.

Иконки PWA пересобираются командой `python3 tools/make-icons.py`.
