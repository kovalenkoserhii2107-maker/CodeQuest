# CodeQuest

Верстка интерфейса космической корпорации **CodeQuest Orbital** на чистых HTML и CSS —
без JavaScript и сторонних библиотек.

## Структура

```
index.html        — центр управления: метрики, флот, миссии, журнал, склады, экипаж
missions.html     — реестр миссий, форма заявки на запуск, решения совета
css/reset.css     — базовый сброс стилей
css/style.css     — дизайн-токены, сетка страницы, шапка, сайдбар, подвал
css/components.css— компоненты: кнопки, бейджи, карточки, таблицы, прогресс, формы
```

## Как смотреть

Открыть `index.html` в браузере — сборка не нужна.

## Особенности

- Тёмная «космическая» тема на CSS-переменных, все цвета и отступы вынесены в токены.
- Адаптивная сетка: сайдбар сворачивается в иконки на планшете и уходит наверх на телефоне.
- Иконки — инлайновые SVG, внешних шрифтов и запросов нет.
- Учтены доступность (`aria-label`, `visually-hidden`, видимый фокус)
  и `prefers-reduced-motion`.
