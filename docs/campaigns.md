# Кампании CodeQuest

При каждом запуске открывается выбор кампании. «Космическая корпорация» запускает существующий маршрут заданий; при возвращении из меню сохраняется последний открытый раздел. «Городской комбинат» — отдельная экономическая песочница в промышленном городе.

## Городской комбинат

Игрок начинает с 1000 ₽, склада на 100 единиц и одного станка. JavaScript покупает лом, производит металл и детали, выбирает покупателей и улучшает оборудование. Прямых кнопок покупки и продажи нет: управление экономикой происходит через код.

Вход — экспорт main(cq) из index.js. Один запуск соответствует одному шагу мира. Автоматизация повторяет проект примерно раз в секунду после завершения предыдущего шага. На выходе в меню запуск отменяется и время останавливается. Офлайн-доход не начисляется.

Доступны cq.getState(), buy, produce, sell, upgrade, print и memory. Цены, спрос, затраты и результат операций определяет движок. getState возвращает копию. cq.memory хранит JSON-данные между шагами, обычные переменные модулей создаются заново.

Учебные ориентиры: первая закупка → партия металла → продажа → прибыльная стратегия → несколько файлов. Все действия доступны сразу, подсказки не заменяют код игрока. В пробном запуске результат и время считаются на копии без изменения денег, памяти и прогресса.

Многофайловый проект поддерживает настоящие ES-модули через существующий загрузчик CodeQuest: относительные импорты, до 20 файлов и 200 КБ кода, без циклов. Скрипт выполняется в отдельном Web Worker, ограничен 3 секундами и 100 командами на шаг. Ошибка откатывает весь шаг. Это учебная среда исполнения, а не средство изоляции недоверенного кода от всех браузерных API.

## Сохранения и проверка

Существующая кампания использует codequest.progress.v2. Песочница использует codequest.city.v1: мир, исходники и память. Сброс песочницы не изменяет космическую кампанию. Повреждённое сохранение не стирается при простом открытии или закрытии кампании; следующее действие или редактирование сохранит новый мир.

Запуск проверки: npm ci; npm test; node tests/check-plant.mjs. Браузерные проверки: установить @playwright/test, выполнить npx playwright install chromium и node tests/campaign-browser.mjs. Workflow Campaign checks запускает существующие проверки, новые проверки движка и Chromium; скриншоты меню и мастерской на десктопе и телефоне доступны в артефактах.


## API и задания мира

Первые шесть заданий проходят полный первый цикл: прочитать мир и вывести состояние, изучить поставщика, купить сырьё, изучить рецепт и запустить партию, дождаться товара, выбрать покупателя, продать товар и сохранить счётчик при автоматизации. Карточка каждого задания показывает цель, понятия JavaScript, нужные методы, заготовку, две подсказки и точное условие проверки. Засчитывается только текущая задача после успешного реального шага; проба и ошибочный шаг ничего не засчитывают. Заготовки не заменяют код автоматически. Весь API доступен независимо от заданий.

API сгруппирован: cq.world, warehouse, market, factory, contracts, logistics, research. cq.print и cq.memory остаются общими. Справочник содержит поиск, фильтры по системам, аргументы, тип результата, ограничения, примеры и ошибки. Эти же объявления типов используются в Monaco. Старые cq.getState/buy/produce/sell/upgrade продолжают работать.

Дальнейшие задачи: выполнить контракт, открыть провод, доставить товар, развернуть параллельные линии и выделить стратегию в модуль.

### Новые механики

- Заказы города: metal-order, parts-order, wire-order. Бесплатное принятие, максимум два активных, фиксированная награда при сдаче всего количества. deadline — последний недоступный для сдачи шаг: сдайте при tick < deadline. Просрочка возвращает заказ в доступные и увеличивает счётчик expired без штрафа. После выполнения обновление через 5 шагов.
- Доставка: courier (1 шаг / 5 ₽ / 12 единиц), rail (3 шага / 8 ₽ / 40 единиц). Один груз на маршрут. Товар, спрос и плата списываются сразу; выручка зачисляется при прибытии. Цена единицы закреплена при отправке. district и electronics требуют доставки; местным покупателям можно продавать напрямую.
- Производство: максимум четыре независимые линии с общим складом и балансом. Цена новой: 1200 ₽ × число уже имеющихся линий. До 8 × уровень единиц в партии. Резерв склада учитывает выход каждой незавершённой партии. Старые job и machineLevel отражают первую линию.
- Исследования: wire за 400 ₽ открывает провод (1 металл + 3 ₽, 1 шаг); efficiency за 600 ₽ уменьшает энергию новых партий на 1 ₽ за единицу. Старые рецепты доступны без исследования.
- cq.market.quote рассчитывает выручку, плату, чистое поступление и canTrade без изменения мира. net не вычитает исторические затраты производства; для прибыли учитывайте метрики revenue − spent.

Сохранение по-прежнему codequest.city.v1: первая схема автоматически получает новые поля без потери денег, файлов, памяти и незавершённой партии. tutorial.completed хранит выполненные задания. Повреждённая новая схема отклоняется с предупреждением.

Дополнительные проверки: tests/check-city-world.mjs (миграция, API, контракты, доставка, линии, исследования, учебные задания, документация) и tests/city-world-browser.mjs (все 11 заданий через настоящий Worker, справочник, подсказки редактора, сохранение, темы и телефон).
