# Карта, путеводитель и конструктор

## Навигация

Четыре раздела: «Код и дашборды», «Мир и экономика», «Задания», «Путеводитель API».
Вкладки поддерживают стрелки, Home и End; панели скрываются, а редактор остаётся
смонтированным — модель и undo сохраняются. Переключение разделов не переводит
игровое время. Автоматизация продолжает работать до выключения или выхода в меню.

## Карта мира

У каждого района своя лёгкая SVG-иллюстрация: комбинат, порт с баржей и северная
станция. Выбор района показывает условия доступа, поставщиков, число покупателей,
событие и ссылки на нужные методы API. Это просмотр; разрешение покупается
только через world.explore в main. Движущийся пунктир обозначает маршрут с грузом
в пути; остальное время он неподвижен. На телефоне карта превращается в карточки.
Движение отключается при prefers-reduced-motion. Иллюстрации включены в офлайн-кэш.

## Конструктор дашбордов

Нажмите «Конструктор» в панели дашборда. Выберите шаблон «Мастерская», «Рынки»,
«Диспетчерская» или «Чистый лист». Добавляйте до 12 инструментов:
показатели баланса/доходов/места, график истории, сравнение цен, таблицы склада,
грузов и заявок, индикатор загрузки линий и заметку.

Настраиваются название, число колонок, заголовок/ширина/порядок виджета, текст
заметки, вид графика (линия/область/столбцы) и товар по умолчанию.
Предпросмотр выполняет настоящий сгенерированный render в отдельном readonly
Worker. Экономика и память не меняются. Пустой график истории нормален до
первого успешного игрового шага.

«Создать JS-файл» сохраняет новый dashboards/name.js и открывает его в редакторе.
Существующие файлы не заменяются. Исходник можно скопировать и посмотреть заранее.
Конструктор создаёт код из выбранных инструментов; он не разбирает произвольные
пользовательские исходники. После создания расширяйте расчёты в JavaScript.
На экране дашборда отдельно доступны настройка раскладки и фильтры. Закрытый
конструктор сохраняет свой черновик до выхода из кампании; после перезагрузки
сохраняются созданный JS-файл, фильтры и раскладка.

Пример финансового экрана: «Баланс» + «Баланс по шагам» + «Запасы склада».
Пример торгового экрана: «Сравнение цен» + «Отложенные продажи».
Пример диспетчерской: «Загрузка линий» + «Грузы в пути».

## Новый формат виджетов

Старые chart без style по-прежнему выводятся линией.

~~~js
{ id: "cash", type: "stat", title: "Баланс", value: state.balance, unit: "₽" }
{ id: "trend", type: "chart", style: "area", title: "Баланс", width: 2,
  points: history.map(p => p.balance), labels: history.map(p => String(p.tick)), unit: "₽" }
{ id: "busy", type: "progress", title: "Загрузка линий",
  value: state.lines.filter(l => l.job).length, max: state.lines.length, unit: "линий" }
~~~

Для progress нужны конечные числа: 0 ≤ value ≤ max, max > 0.
Графики показывают шкалу, подписи и min/max; на компьютере наведение на точку
или столбец показывает подпись и значение. До 120 точек на график.

## Путеводитель

«Первые действия» объясняет чтение, производство, продажу, разрешения/доставку
и заявки: цель, действия, готовый main, ожидаемый результат и частая ошибка.
«Мои дашборды» объясняет выбор инструментов, render, виджеты, фильтры и HTML/CSS.
«ID, время и ошибки» показывает программные ID и ссылки на каталоги API,
порядок команд, работу памяти, отличия прибыли от выручки и способы отладки.
Поиск методов и прежний справочник доступны ниже путеводителя.

## Проверки

npm test включает tests/check-visual-workbench.mjs: реальные ES-модули генератора,
все источники/шаблоны, режим чтения, ограничения, совместимость старых графиков
и исполняемые примеры путеводителя.
tests/visual-world-browser.mjs проверяет вкладки и сохранение модели, карту,
подсказки API, конструктор/экспорт, защиту файлов, фильтры, телефон и обе темы.
Скриншоты сохраняются в campaign-screenshots. Ручной визуальный просмотр
скриншотов в текущей сессии недоступен; результат проверяется кодом и Chromium.
