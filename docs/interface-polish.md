# Отзывчивость и справка API

Кнопки методов в карточке задания открывают точную справку. Фильтры раздела и типа сочетаются с поиском; Escape сбрасывает фильтры. Чтение разрешено в main и render, команды — только в main. Вывод и память выделены отдельно. Чтение после команды видит её результат внутри текущего запуска; время сдвигается после успешного main. Ошибка отменяет команды и память.

В справке можно скопировать фрагмент или полный export function main(cq). Примеры не запускаются и не заменяют исходники. При недоступном буфере код выделяется для ручного копирования. Кнопка возвращает к редактору.

Настройка автообновления дашборда сохраняется. Выключение отменяет ожидающее обновление кода; ручная кнопка и завершение игрового шага по-прежнему обновляют снимок. Поля показателей мира сохраняют DOM; изменившееся значение получает короткую анимацию. Открытый пример отложенной продажи сохраняется при обновлении мира. Анимации и плавные переходы учитывают prefers-reduced-motion.

Проверки: npm test и tests/api-polish-browser.mjs дополняют существующие сценарии Chromium. Покрываются переходы из задания, фильтры и буфер обмена, сохранение автообновления и отмена таймера, производство, откат памяти и мира, проба и продажа, уменьшение движения и ширина 390 px в двух темах. Скриншоты сохраняются в campaign-screenshots; ручной просмотр изображений в текущей сессии недоступен.
