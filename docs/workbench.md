# Рабочее пространство и ваши дашборды

Проводник поддерживает папки, вложенные JS-модули, вкладки, создание, удаление и переименование. При переименовании пересчитываются относительные импорты перемещённых файлов и их зависимых модулей. index.js остаётся точкой входа мира. До 20 файлов и 200 КБ, пути до 160 символов и 6 частей. Пустые папки, активный файл и вкладки сохраняются.

Выберите «Код», «Дашборд» или «Вместе». Каждый дашборд — JS-файл внутри dashboards/, который экспортирует render(cq, view). Функция исполняется отдельным Worker до 3 секунд. Она читает мир без перевода времени; команды изменения экономики запрещены, изменения cq.memory не сохраняются. Основной скрипт index.js работает отдельно.

Верните объект title, columns (1–4), widgets. Виджеты:

- stat: id, title, value, unit, tone (ok/warn/danger).
- text: id, title, text.
- table: id, title, columns (заголовки), rows (массивы значений).
- chart: id, title, points (до 120 чисел), labels.
- У всех width (1–4); уникальный стабильный id используется для сохранения раскладки.

На экране можно изменить число колонок, порядок и ширину виджетов, скрыть их и восстановить. Настройки хранятся для каждого файла, доступны сброс и несколько представлений.

Фильтры controls — массив {id,type,label,value,options}; type: select/number/text; у select options [{value,label}]. Значения доступны как view.inputs[id]. Изменение фильтра пересчитывает дашборд без запуска экономики.

Для свободного дизайна верните html, css и height (200–1200). Ваша функция render вычисляет HTML из данных мира; CSS и HTML отображаются в sandbox iframe. Скрипты внутри HTML не исполняются: логику пишите в render и импортируемых модулях. CSS не меняет интерфейс приложения. Стандартные виджеты выводят данные как текст.

Новая игра содержит overview.js и markets.js. В существующем проекте кнопки примеров создают новый файл, не заменяя код. Представление обновляется при выборе, ручном обновлении, изменении фильтра и успешном шаге мира.

## Расширение мира

Общий мир: промышленный город city, свободный порт port, Северные высоты highlands. cq.world.getRegions/getEvents читают карту и события, cq.world.explore открывает доступ за 600/1000 ₽.

У поставщиков и покупателей region и locked. cq.market.buy(product,quantity,supplierId) выбирает yard (лом за 4), port-yard (лом за 3), northern-metal (металл за 12). Нужен доступ к региону. Дополнительные рынки испытывают периодические изменения цен.

courier обслуживает city; rail — city/highlands; barge — port (5 шагов, 20 ₽, до 60 единиц). Неподходящий маршрут не отправит груз. Цена отправленного груза закреплена.

Исследование circuits за 800 ₽ открывает circuit: 3 wire + 8 ₽, 4 шага. Северный рынок принимает схемы.

cq.analytics.getHistory(limit) возвращает до 120 снимков: tick, balance, revenue, spent, inventory, prices. Используйте map/filter/reduce для графиков и стратегии. cq.project.listFiles/readFile читает исходники.

Мир мигрирует к schema=3 в прежнем сохранении codequest.city.v1 без потери денег, исходников, партий, перевозок, памяти и учебного прогресса. Дополнительно сохраняются workspace и dashboards.

Проверки: npm test и прежние сценарии Chromium дополнены check-workbench.mjs и workbench-browser.mjs. Последний проверяет файловые операции, дашборды из JS, раскладки и фильтры, сохранение, запрет записи в мир, iframe, регионы, мобильную ширину и темы.
