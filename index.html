Ваши панели

Каждая панель — функция, которую вы написали. Она запускается заново при каждой отрисовке.

Что панель умеет рисовать

Верните из функции объект с полем type — и вместо числа появится график. Остальные поля (title, note, rows, list) работают как раньше.

  • gauge — круговая шкала доли от максимума. { type: "gauge", value: 340, max: 1000, label: "Масса", unit: "т" }
  • fill — полоса заполненности. { type: "fill", value: 7, max: 10, label: "Трюм" } Добавьте tone: "progress", если полная полоса — это хорошо.
  • balance — шкала с нулём посередине: значение может быть отрицательным. { type: "balance", value: -20, max: 120, label: "Энергия" }
  • bar — столбики по списку. { type: "bar", items: [{ label: "Руда", value: 12 }], unit: "т" }
  • spark — линия по точкам. { type: "spark", points: [3, 7, 5, 9] }

Данные берите из базы — тогда график живёт сам: dashboard.add("mass", db => ({ type: "bar", items: db.all("ships").map(s => ({ label: s.name, value: s.mass })) }))
